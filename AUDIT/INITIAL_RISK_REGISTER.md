# Initial Risk Register

| Risk ID | Severity | Area | Finding in Initial Codebase / Manuscript | Impact |
|---|---|---|---|---|
| RISK-01 | **CRITICAL** | Timestamp & Look-Ahead | `binance_vision.py` and `indodax_history.py` both assign candle `open_time` to `timestamp_utc` while retaining the candle's `close` price. `_asof_window_match` in `aligner.py` uses `direction="forward"` from `pub_ts_utc`, matching the bar whose `open_time == pub_ts_utc` (e.g., 09:15–09:20 UTC), whose `close` is not realized until 5 minutes *after* JISDOR publication. Manuscript claims it matches "the first closed five-minute candle". | 5-minute look-ahead bias in all daily JISDOR-synchronized panels (`btc/eth/xrp_jisdor_sync_primary.csv`) and offset checks. |
| RISK-02 | **CRITICAL** | Deterministic Specification | `sec4_econometric_methodology.tex` specifies a restricted constant inside the cointegrating relation ($H_1^*(r)$, `deterministic="ci"`). However, `ecm.py` defaults to `det_order="co"`, `cointegration.py` uses `coint_johansen(..., det_order=0)` (unrestricted constant `co`), and `bootstrap.py` uses `det_order=0`. | Method-implementation mismatch between manuscript equations and code. |
| RISK-03 | **CRITICAL** | Sequential Bootstrap Rank | `bootstrap.py` (`null_imposed_vecm_residual_bootstrap`) only tests $H_0: \mathrm{rank}(\Pi) = 0$. It does not test $H_0: r \le 1$ (or $H_0: r \le 2$ for 3-var), which is required to establish $r=1$ via sequential testing. | Incomplete bootstrap rank inference; $r \le 1$ relies solely on asymptotic critical values. |
| RISK-04 | **HIGH** | Bootstrap Config & MC | `config/econometrics.yaml` still lists `method: "null_imposed_vecm_iid_residual_bootstrap"` (stale label). `evaluate_bootstrap_size_and_power` uses `burn=80`, single parameter set, no MC standard errors reported in output, and no block-length sensitivity. | Metadata mismatch and incomplete Monte Carlo validation. |
| RISK-05 | **HIGH** | Half-Life Interpretation | `sec5_empirical_results.tex` foregrounds the companion-matrix slowest-mode half-life (`25.08` 5m bars) vs scalar (`12.09` bars), while `intraday_and_tar_results.json` also reports `half_life_irf_local` (~1.13 bars) and `half_life_irf_gen` (~0.95 bars). Mode loading onto the ECT $\beta' Y_t$ is unverified. | Potentially misleading economic interpretation if the 25.08-bar mode barely loads onto the ECT. |
| RISK-06 | **HIGH** | HAC & Residual Diagnostics | 5-minute VECM uses only `hac_lags=12` (1 hour), and daily uses `hac_lags=5`, despite strong Ljung-Box and ARCH-LM rejections ($p < 0.001$). No bandwidth sensitivity (`12, 24, 48, 144, 288`, data-driven) or block-bootstrap coefficient SEs. | Weak-exogeneity and adjustment p-values could be sensitive to HAC bandwidth. |
| RISK-07 | **MEDIUM** | Stale Prices & Zero-Volume | Primary 5m panel retains 11,533 zero-volume bars (`is_active_both_indo == False`). Active-volume check drops rows irregularly, compressing time. No sensitivity to stale-bar thresholds on the regular grid. | Potential distortion of short-run dynamics by stale/forward-filled bars. |
| RISK-08 | **MEDIUM** | Structural Stability | Only event windows ($\pm 30$d / $\pm 15$d) and one 2023 Chow test are run. No rolling/recursive VECM or subsample cointegration/adjustment stability analysis across 2021–2026 regimes. | Unverified parameter stability across 6-year sample. |
| RISK-09 | **MEDIUM** | CFX Event Study | +17.37 bps CFX Nov 1, 2024 association is reported in Abstract/Intro/Results, but sensitivity to window lengths (7d, 15d, 30d, 60d), placebo dates, outlier influence, and pre-trends is not systematically documented. | Risk of over-interpreting a window-specific or outlier-driven shift. |
| RISK-10 | **MEDIUM** | Reproducibility & Paths | `config/full_research.yaml` hardcodes `/Users/naresh/Library/TinyTeX/bin/universal-darwin/pdflatex`. `data/raw/` is missing from `idr-stablecoin-fx-basis` (exists in sibling `indonesian_crypto_research_final/`). No `AUDIT/` or `REPRODUCTION_MANIFEST.json`. | Clean-machine reproduction fails without path fixes and clear raw-data documentation/provenance. |
